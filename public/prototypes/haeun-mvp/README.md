# 하은 MVP 플로우 초안

선영님 초안과 비교하기 위한 독립 프로토타입입니다. 기존 React 앱과 별도로 `public/prototypes/haeun-mvp/`에 보관합니다.

## 실행

프로젝트 개발 서버에서는 `/prototypes/haeun-mvp/`를 엽니다. 이 폴더에서 `node server.mjs`를 실행하면 `http://127.0.0.1:4173`에서도 볼 수 있습니다. 외부 패키지 설치는 필요 없습니다.

검사: 이 폴더에서 `node --test flow.test.mjs`.

## 현재 흐름

- 스플래시 1.5초 → 로그인 → 약관동의 → 직장인 → 전월세 세입자 → 대출 보유 여부
- 로그인 버튼만 동작하며 실제 인증은 하지 않습니다.
- 필수 약관 2개 동의 후 다음 버튼 활성화. 약관 상세 화면은 미구현입니다.
- 있어요: 건수 → 총 원금 → 월 상환액을 한 화면에서 Enter/확인으로 순차 입력 → 전월세 보증금 선택 → 결과
- 보유자 결과는 미승인 시안과 가능성 O 시안을 번갈아 보여줍니다. 입력값에 따른 승인 판정이 아닙니다. 세 번째 결과 시안은 아직 전달받지 않았습니다.
- 없어요: 희망 금액 → 목적 선택 → NoLoan 결과 → 홈
- 05~09 건너뛰기 → NoOB_NoMD 홈
- NoOB_NoMD와 OB_NoMD 홈 두 탭에 카드·이미지·배너와 내부 스크롤을 반영했습니다. 상단 별은 기존 저장소 아이콘을 재사용하며 보안·알림 및 하단 아이콘도 유지합니다.
- InOB_NoMD는 주요 영역만 구현한 초안입니다. OB_MD 완료 화면은 요청에 따라 Asset/Loan 모두 빈 화면이며 미리보기에서 진입·복귀만 연결했습니다.
- OB_NoMD의 대출 찾기 탭에서 AI금리예측 화면을 열고 뒤로가기로 복귀합니다. 수치는 임시/가림 표시이며 실제 예측 API는 없습니다.
- 상태선택 아래 화면선택 드롭다운에서 온보딩·결과·홈·AI금리예측·팝업 등 26개 화면을 바로 검토할 수 있습니다.
- 별 클릭 → 즐겨찾기 팝업 → 편집하기 → 퀵메뉴 항목 추가 화면을 연결했습니다. 완료는 즐겨찾기 팝업으로 돌아옵니다. X·바깥 영역·Esc로 닫을 수 있습니다.
- 첨부 SVG 원본 아이콘을 사용했습니다. 메뉴 선택·저장 및 메뉴별 이동은 아직 미구현이며, 사용/선택 개수는 제공된 시안의 임시 표시입니다.

## 범위

실제 승인 조건, MyData 연결, DB/API, 저장 및 이탈 재개 정책은 미확정/미구현입니다. 입력값은 메모리에만 유지되며 새로고침 시 초기화됩니다. 결과 순환은 같은 페이지 실행 중 '처음부터'를 눌러도 이어집니다.

화면 밖에는 프레임 이름, 상태선택, 이전/다음, 처음부터만 표시합니다. 실제 프레임 최소 크기는 360×780px이며 미리보기만 창 크기에 맞춰 축소합니다.

디자인 시스템은 미완성입니다. 제공받은 버튼 상태 및 입력 스타일만 공통 CSS에 반영했습니다. Figma는 수정하지 않았으며 레이어 네이밍은 사용자의 추후 수정 요청을 따릅니다.
